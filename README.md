# 🌐 Obys Agency Clone

A visually stunning, animation-rich website inspired by the original Obys Agency. Built using **HTML**, **CSS**, and **JavaScript**, this project showcases creative scroll interactions and modern web animation techniques.

## 🚀 Live Demo

👉 [Click here to view the live site](https://vishant8491.github.io/Obys-Agency/)

---

## ✨ Key Features

- 🎞️ Smooth scroll-based animations and transitions
- 📱 Fully responsive layout for mobile, tablet, and desktop
- 🎨 Clean and minimal UI inspired by creative agencies
- ⚡ Optimized performance for modern browsers (Chrome, Firefox, Edge)
- 🧠 Semantic and organized code structure for easy maintenance
